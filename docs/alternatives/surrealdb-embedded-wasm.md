# SurrealDB Embedded WASM as a Local-First Client

*Part of [Alternative Architecture Exploration](README.md).*

### 7.4 SurrealDB embedded WASM as a true local-first client

`@surrealdb/wasm` genuinely runs SurrealDB in-browser (memory or IndexedDB). However, SurrealDB's own maintainers have stated on GitHub that local-first sync with a remote server "is not on the near-term horizon." Nothing beyond community DIY projects exists for this today. **This is aspirational, not shippable in 2026 — skip it entirely as a sync strategy for now.**
